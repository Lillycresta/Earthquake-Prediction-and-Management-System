# GeoPulse

University mini project for Data Mining and Wrangling.

## Run

```bash
python preprocess_train.py
python app.py
```

Open `http://127.0.0.1:5000`.

## Scope

The application uses genuine USGS historical data for magnitude classification. It does not claim to predict exact future earthquake occurrences.

## Main pages

- Home
- Dashboard
- Analysis
- Prediction
- Management
